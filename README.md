# E-commerce Site: Project Ongoing
# 🛒 Full Stack E-Commerce Platform

A modern, scalable full-stack e-commerce application built with performance, security, and real-world usability in mind. This project demonstrates end-to-end development including authentication, payments, admin management, and optimized backend services.

---

* Secure signup & login functionality
* Protected routes and role-based access
* Data protection and secure API handling

---

### 🛍️ E-Commerce Core

* Product listing and category management
* Dynamic shopping cart functionality
* Smooth cart & checkout experience
* Coupon/discount system
* Order processing flow

---

### 💳 Payment Integration

* Secure payment processing using Stripe
* Real-time checkout handling

## ⚙️ Project Setup

### 1. Clone the repository

```bash
git clone https://github.com/your-username/your-repo.git
cd your-repo
```

### 2. Install dependencies

```bash
npm install
cd backend && npm install
```

### 3. Setup environment variables

Create a `.env` file inside the backend folder:

```env
PORT=5001
MONGO_URI=your_mongodb_connection
JWT_ACCESS_SECRET=your_secret
JWT_REFRESH_SECRET=your_secret
STRIPE_SECRET_KEY=your_key
UPSTASH_REDIS_REST_URL=your_url
UPSTASH_REDIS_REST_TOKEN=your_token
```

---

### 4. Run the project

```bash
npm run start
```
